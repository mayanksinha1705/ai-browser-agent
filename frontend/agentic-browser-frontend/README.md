# Agentic Browser — Landing Page

A modern, dark, developer-focused landing page for an AI Agent Browser
product. Built with Next.js 15 (App Router), Tailwind CSS, shadcn/ui,
Framer Motion and lucide-react.

## Sections
Hero, Features, Installation Guide (5 steps, tabbed code blocks with
copy buttons + custom syntax highlighting), How It Works, Code Demo,
Integrations, Pricing, Testimonials, FAQ, Footer.

## Quick start
```bash
yarn install       # or: npm install
yarn dev           # http://localhost:3000
```

## Build
```bash
yarn build && yarn start
```

## Notable files
- `app/page.js`     — the entire single-page site
- `app/layout.js`   — fonts, metadata, dark theme
- `app/globals.css` — tokens, gradients, terminal caret, particles
- `components/ui/*` — shadcn primitives

Enjoy!
